# Deadlock Seasonal Stats · 0.7.0

Мод Deadlock в формате VPK: ранги и винрейты текущего и предыдущего сезонов, списки героев и кнопка Statlocker.

**Готовый мод:** [pak80_dir.vpk](seasonal-stats/dist/pak80_dir.vpk) · [SHA-256](seasonal-stats/dist/SHA256.txt) · [Подробная инструкция](seasonal-stats/dist/README-RU.md)

## Установка

1. Закрой Deadlock.
2. Скачай `pak80_dir.vpk` и замени прежнюю копию этого мода в `Deadlock/game/citadel/addons/`.
3. Убедись, что addons подключены менеджером модов или строкой `Game citadel/addons` выше `Game citadel` в `FileSystem/SearchPaths` файла `gameinfo.gi`.
4. Перезапусти игру. В окне должна быть версия `Seasonal Stats 0.7.0`.

Оба сезонных ранга и общие винрейты видны одновременно. Кнопки переключают списки героев между сезонами. Порог — 10 рейтинговых матчей на герое за выбранный сезон.

## Данные

Источник — публичный Deadlock API. Ранг берётся из последнего записанного рейтингового матча внутри соответствующего сезона; история может быть неполной и отставать от игры. Медаль прошлого сезона не переносится в текущий.

Статический HTTPS-мост: https://deadlock-seasonal-bridge-rm24.yokodav27.chatgpt.site/

Мост не содержит базы данных и секретных ключей. Закрытие репозитория не меняет существующую публичную доступность моста, нужного модификации. В каталоге `seasonal-stats/https-bridge/dist` сохранены его исходники без служебных данных хостинга.

## Сборка и проверки

Нужны Python 3.10+ и Node.js 18+. Внешние библиотеки для сборки VPK и логических тестов не требуются.

```sh
cd seasonal-stats
python build.py
node test.js
node test.js --profile
```

Результат: `seasonal-stats/dist/pak80_dir.vpk`. Сохранённые layout-файлы сверены с Deadlock build 6860. После обновлений игры совместимость нужно проверять заново.

Основные исходники 0.7.0: `source/seasonal_stats_v070.js`, `source/bridge-v070.js` и `build.py`. Файлы без суффикса версии сохраняют совместимость старого протокола. `test-legacy.cjs` проверяет прежний интерфейсный код.

Проверены расчёты, границы сезонов, калибровка, отсутствие переноса медали между сезонами, переключение героев, смена игрока, кэш, частичные ошибки, реальные ответы API и контрольные суммы VPK. Внешний вид 0.7.0 в игровом клиенте пока не проверен.

Штатные фрагменты интерфейса и игровые ресурсы принадлежат Valve. Данные предоставляет неофициальный Deadlock API; проект не связан с Valve или Statlocker.
