# Deadlock Seasonal Stats · 0.8.0

Мод Deadlock в формате VPK: ранги и винрейты текущего и предыдущего сезонов, списки героев, проверка пати и кнопка Statlocker.

**Готовый мод:** [pak80_dir.vpk](seasonal-stats/dist/pak80_dir.vpk) · [SHA-256](seasonal-stats/dist/SHA256.txt) · [Подробная инструкция](seasonal-stats/dist/README-RU.md)

## Установка

1. Открой путь Deadlock\game\citadel\addons
2. Скачай `pak80_dir.vpk` и перемести в папку
3. Убедись, что addons подключены менеджером модов или строкой `Game citadel/addons` выше `Game citadel` в `FileSystem/SearchPaths` файла `gameinfo.gi`.
4. Запусти Deadlock

Оба сезонных ранга и общие винрейты видны одновременно. Кнопки переключают списки героев между сезонами. Порог — 10 рейтинговых матчей на герое за выбранный сезон.

## Пати

Блок «ПАТИ» показывает, с кем игрок играл в одной пати, и умеет проверить конкретную пару:

- Список — до трёх напарников с наибольшим числом совместных пати-матчей, с винрейтом этих матчей.
- Проверка пары — введи Account ID второго игрока и нажми «Проверить»: мод ответит «В пати с …: N матчей» или «совместных пати-матчей нет».

Пати определяет сам API: два игрока считаются напарниками, если они были в одной команде и на момент матча состояли в друзьях Steam. Поэтому проверка опирается на публичные списки друзей: у части аккаунтов их нет, и тогда список пуст, а по паре ответ может отличаться в зависимости от того, чей профиль доступен. Проверка смотрит данные в обе стороны, чтобы это компенсировать.

Для пати нужен мост — он уже опубликован из этого репозитория: `https://romareyme.github.io/deadlock-seasonal-stats/`. Pages настроен (Source: **GitHub Actions**), публикация идёт автоматически: пуш, меняющий `seasonal-stats/https-bridge/dist/`, запускает `.github/workflows/bridge.yml`. Старый мост `…yokodav27.chatgpt.site` больше не используется.

Если сайт ещё не поднят, сезоны, ранги и герои работают как раньше, а в блоке «ПАТИ» появляется надпись «Мост не обновлён: нужен v0.8.0».

## Данные

Источник — публичный Deadlock API. Ранг берётся из последнего записанного рейтингового матча внутри соответствующего сезона; история может быть неполной и отставать от игры. Медаль прошлого сезона не переносится в текущий. Пати берётся из `/v1/players/{id}/mate-stats?same_party=true`, имена — из `/v1/players/steam`.


## Сборка и проверки

Нужны Python 3.10+ и Node.js 18+. Внешние библиотеки для сборки VPK и логических тестов не требуются.

```sh
cd seasonal-stats
python build.py
node test.js
node test.js --profile
```

`test.js` прогоняет наборы сезонной статистики, пати и маршрутизатора моста. Штатные профили `--profile` проверяют полную страницу профиля вместо карточки в контекстном меню. `python build.py --bridge <url>` меняет адрес моста, вшитый в VPK.


Штатные фрагменты интерфейса и игровые ресурсы принадлежат Valve. Данные предоставляет неофициальный Deadlock API; проект не связан с Valve или Statlocker.
